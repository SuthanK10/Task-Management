# Task Management REST API

A technical assessment project implementing a robust backend REST API and a basic vanilla frontend to manage personal tasks.

## 🚀 Tech Stack

* **Backend:** Laravel 12.x, PHP 8.2+
* **Database:** MySQL
* **Authentication:** Laravel Sanctum (Token-Based Authentication)
* **Frontend:** Plain HTML, Vanilla CSS, and JavaScript (Fetch API)

## 🎯 Features Core Requirements
- **Secure Authentication:** Users can securely authenticate and receive Sanctum API tokens.
- **Task Management:** Users can view, create, edit, and delete their own tasks.
- **Data Protection:** Users can ONLY access their own records.
- **RESTful Endpoints:** Standardized JSON responses for all actions.
- **Filtering & Pagination:** Fetch paginated tasks with dynamic filtering options.
- **Soft Deletion:** Safely soft-delete tasks instead of permanent erasure.
